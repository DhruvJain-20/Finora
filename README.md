# 💰 Finora — AI-Powered Personal Finance Copilot

**Finora** is a full-stack personal finance application that helps users track income and expenses, manage monthly budgets, analyze spending patterns, set savings goals, and explore their financial data through an AI-powered finance assistant.

🔗 **Live Demo:** https://finora-zdvy.onrender.com

## ✨ Features

- **Income & Expense Tracking** — Add, view, edit, and delete financial transactions.
- **Budget Management** — Create monthly budgets and monitor spending against budget limits.
- **Financial Analytics** — Explore spending patterns through category breakdowns, historical analysis, and charts.
- **Savings Goals** — Set savings targets, track progress, and monitor goal deadlines.
- **AI Financial Insights** — Generate personalized insights based on available financial data.
- **AI Finance Chatbot** — Ask questions about monthly spending, expense categories, budgets, savings goals, and general personal finance.
- **Secure Authentication** — Sign up, log in, and sign out using Supabase Authentication.
- **User Data Isolation** — Use Supabase Row Level Security (RLS) to restrict access to each user's financial records.

## 🏗️ Application Overview

Finora connects an EJS-based frontend to an Express.js backend. The backend handles application routes, authenticated requests, and financial calculations. Supabase stores financial records and manages authentication, while the Gemini API powers AI-generated insights and conversational finance assistance.

## 🔐 Security

- Authentication through Supabase.
- Row Level Security policies for user-specific financial records.
- API keys stored in server-side environment variables.
- Authenticated routes for protected pages and financial operations.
