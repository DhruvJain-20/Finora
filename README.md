# 💰 Finora

### AI-Powered Personal Finance Copilot

Finora is an AI-powered personal finance copilot that helps users track
expenses, manage budgets, analyze spending patterns, set financial goals,
and get personalized financial insights.

## 🚀 Features

- Expense & income tracking
- Budget management
- Financial analytics
- Financial goals
- AI Finance Copilot
- Spending insights
- Expense forecasting

## 🛠️ Tech Stack

- HTML5
- EJS
- CSS3
- Javascript
- Node.js
- Express.js
- PostgreSQL / Supabase
- Gemini API
- Git & Github
- Vercel
